### 📬 [sme-inbox-parser](https://github.com/challanamuskan/sme-inbox-parser)
> Parse WhatsApp, Gmail & website leads into clean CRM-ready CSV

Every Indian SME manages orders across WhatsApp threads, Gmail, and website forms — scattered across 3 inboxes. This tool unifies all three.

- WhatsApp `.txt` export parser (iOS + Android format)
- Gmail thread parser via OAuth 2.0
- Website contact form CSV parser (auto-detects columns)
- Unified output: clean CSV or Google Sheets push
- Streamlit drag-and-drop web UI + CLI

`Python` `Gmail API` `WhatsApp` `Google Sheets` `CLI` `Streamlit`
